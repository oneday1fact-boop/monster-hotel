# 1.10 手機操作質感

- DOM 按鈕及封面 Canvas 按鈕加入按壓、放手回彈；移出按鈕再放手會取消操作。
- 小型金色觸控光點有數量上限、無點擊攔截、自動清理。
- 全螢幕視窗入場約 180ms，關閉約 120ms；選關翻頁分批淡入。
- 封面、大廳、進關、過關與下一關採短淡出／淡入；不依賴 View Transitions，避免暫停 Phaser 與金幣計數的畫面更新。
- 開關滑動、已改變的解謎物件和回饋文字有局部動態。解謎操作不等待選取動畫播完。
- 遵從系統減少動態效果設定及原有音效／震動偏好。
- 儲存格式、13 關內容、首次派獎及相牆保持兼容；育成系統繼續暫緩。

## 驗證與限制

`npm test`、`npm run build`、`npx playwright test`；新增按住後移出取消、鍵盤焦點、舊 WebView 過渡、減少動態效果、下一關及重複派獎回歸測試。

`node scripts/record-game-feel.cjs` 以實際瀏覽器輸入錄製，回訪玩家測試存檔解鎖已有關卡；Canvas2D 僅用於軟件錄影。影片是 H.264／yuv420p，另有 GIF。Android APK 的網頁資源逐檔比對正式 build，並驗證簽章。實機流暢度及震動手感仍需 Android 試玩，不能從雲端錄影保證幀率。
