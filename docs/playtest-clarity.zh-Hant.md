# 1.5 試玩回饋：看得明嘅線索同道路

主路線調整為：迎賓配房 → 蛋糕失蹤案 → 行李道路滑塊 → 現實與夢境找不同。

## 第一關迎賓

第一晚先介紹月毛、豆豆、燈燈、卷卷及佢哋嘅需要；按「迎接第一批住客」後，角色陸續進場。只保留一個配房關，名字下方有文字需要，房內有文字條件。已完成第一關嘅舊玩家重玩可直接進入配房。

## 蛋糕案

房內有真正睇得到、可以點選嘅繃帶腳印、沾糖霜嘅布、茶車絲帶；空蛋糕盒亦可查看。收集後保留物件，同步在證據欄顯示相同縮圖及短句。三個線索齊先可推理住客，唔再靠三個空泛嘅「調查」掣。

## 道路滑塊

3×3 格，八塊路磚、一格空位。玩家只能將空位上下左右旁邊一塊滑入，不能跳格、不能旋轉。每塊磚都畫出實際道路，入口有旅行箱、出口有小柚。判定會檢查路段互相連接，以及入口左側、出口右側接通；唔係只要有空格便算有路。初始盤面可用六次滑動接通，路磚有滑動動畫，成功後行李沿接通路線行走。

## 找不同

同一張原創客房底圖左右對照；只有五個事先設計嘅物件差異：燈顏色、星徽、鎖匙、地毯顏色、旅行箱／蛋糕。兩邊都可以點，找到後同步標記同一位置。重複點擊不重複計數，其他相同位置不會算答中。圖片保持靜止，唔再用種子、澆水、鎖匙嘅時段切換流程。直向後備版面將兩幅圖上下排列。

## 資料及驗證

繼續使用原有錢包、完成紀錄、裝飾及場景。新草稿用 v2 鍵；蛋糕可讀取舊證據，已換玩法嘅道路及夢境草稿由新規則開始。完成紀錄及已派金幣不重設，所以重玩新玩法亦不會重複派獎。

測試涵蓋完整路線、正確與錯誤操作、途中存檔、重複獎勵、語言切換、離線／儲存失敗及多種畫面尺寸。示範 PNG、H.264 MP4 與 GIF 由真實運行版本錄製。實體 Android 安裝、觸覺及流暢度仍需真機試玩。
