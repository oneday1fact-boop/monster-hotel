# 1.9：三款住客遊戲及合照收藏

本次按最新優先次序先完成香氛調配室、鎖匙櫃嘅秘密、怪物大合照，以及酒店相牆。餵食、好感度等育成部分未加入，留待之後。

## 香氛調配室

三種香味共十二層，五瓶每瓶容量四層。點來源再點目的，只有空瓶或頂層同味可接收；同味頂層一次倒出至接收瓶滿。保留兩個空瓶周轉；不限制步數、沒有倒數，最後三瓶裝滿各一種，餘下兩瓶空。

模型驗證數量守恆、容量及頂層規則；預設盤面最少十次有效倒瓶可解。顏色同時有圖案及名稱，不只靠顏色分辨。最多保留四十個合法撤回快照並保存草稿。倒瓶時短暫播放傾瓶／香氛水流，動作期間避免重複輸入；減少動態時立即更新。

## 鎖匙櫃嘅秘密

三個鎖孔、五種不重複圖案，共六十個可能密碼。每次結果分「啱位」及「圖案啱但位置錯」，不重複計分。選已使用的鎖匙會交換位置，毋須找臨時圖案調位。試過的組合與回饋保留，每頁兩筆，使用固定翻頁，無捲動。重複提交不增加紀錄；沒有次數上限、扣金幣或付費重試。

每次結果由真實密碼重算，顯示仍有幾個可能，沒有直接列答案。已解草稿重新進入仍可完成，獎勵只派一次。

## 怪物大合照

六位原創住客各有身形。點兩個名字換位，再選人調姿勢。要滿足後排／前排要求、前排左傾／正面／右傾姿勢，以及六張面都在相框內而且未被後畫角色遮住，才可拍攝。面孔提示採與場景一致的座標與遮擋範圍；修正過早期邊緣住客裁切的情況。角色保持比例，所有姓名控制留在相框外的固定按鈕列，不會因姿勢被裁切。

按快門後才將構圖存入 `photos.party`，包括順序及姿勢；只排好但未按快門不會解鎖收藏。重拍可以更新構圖，不重複派獎。相牆用同一套角色素材與構圖重現，不需要相機權限或網絡，也不向外上傳照片。相片重溫不顯示解謎用的面孔標記。

## 相容與版面

十三關路線追加三關，舊完成 ID、錢包、場景、布置與草稿不重設。新關首次各五百，現有路線共六千零五十。照片是 v1 存檔的新增可選欄位，只有合法構圖才恢復；損壞照片不會清空錢包。

新三關草稿各自 v1。大廳使用四個獨立按鈕，包括酒店相牆；所有內容固定畫面，長推理紀錄翻頁。英文與繁體中文均有直接可見的目標、規則及回饋。收成效果及原創角色動態延續 1.8，減少動態設定仍生效。
