# 1.22 偵探試玩章與四房新翼

本版先提供一宗可完整完成的原創案件，供玩家試玩後調整節奏與難度。參考的是觀察、比對、出示矛盾及重組事件的偵探遊戲設計方法，沒有複製現有遊戲的角色、劇情、台詞或素材。沒有新增主目錄「故事模式」。

## 入口與玩法

先完成第一次配房，在「我的旅館」中央登記枱點事件簿。神秘住客以原創兜帽造型到訪，留低一宗昨夜的怪事。調查場景明確標示為昨夜重構，不改變現時旅館住客行程或把已購房間重新鎖上。

案件〈鎖住的房間與一杯茶〉使用四間免費房，沒有擴建購買門檻。月光客房檢修、確認空房並封門後，竟然出現暖茶。玩家可以：

- 放大四房，檢查場內實際畫出的物件，將觀察記入證物簿。不是撳一排「搜尋」文字按鈕後憑空得到證物。
- 問月毛、小豆、燈燈與卷卷不同話題，保留已聽到的關鍵證詞。
- 比較服務卡的星形壓印與斜角，和三人的服務章冊逐項核對。
- 親手向下拉送餐格的拉環，看茶盤在停電情況下升到頂。拉得不足或觸控取消不記作完成；鍵盤亦可操作。
- 向小豆出示已取得的證物，反駁「送餐格只可用電」。出示錯誤證物會說明關聯不足，不扣金幣或清空已收集資料。
- 重組人物、路線、送達時間與原因。錯誤答案會按門封、窗塵、服務章、發條鐘或借茶紙給出具體矛盾提示，而非隨機紅叉。

七件證物隨時可用固定分頁重溫，沒有捲動清單、計時、生命或付費提示。住客採單姿態分層連續呼吸、眨眼及問話反應；不會切兩幅人物圖代替動作。

## 案件規則與完整解釋

劇透：小豆用自己的服務章，在 23:54 手動升起送餐格，向害怕見人的神秘住客送暖茶。門封與窗扣沒有被破壞。送餐格到頂才拉動發條出單鐘，所以記錄的是送達時間；不把訂茶時間當成送達時間。服務章冊明確交代今夜沒有借出或遺失個人章，以保持本案身份推斷的一致性。

首次有效結案獎勵 500 金幣並播放收成效果；重玩沒有重複金幣。證物、已聽證詞、反駁結果、推理選擇及完成紀錄保存在原有本機存檔的獨立 `teaCase` 欄位，不改動舊小遊戲的完成身份。中途退出可續查，結案可重查；儲存失敗不派獎或標記完成。

這是第一宗試玩案，不代表已完成整條偵探主線。神秘人的真正身份與月牙舊鎖匙只作後續懸念，後續案件未實作。

## 四房新翼

原有四房畫面加上四個擴建門牌，直接顯示鎖及金幣價格。點門牌或左下「新翼客房 · 四房」，直接切到四間大房的新翼畫面；不必先打開八房地圖。新翼使用獨立的四房原畫：書室、觀星室、音樂室、烘焙房。開放後有現有住客活動，鎖房不會生成住客。

沿用 1.21 的 `hotelRooms` 所有權、價格及先決條件，不重收已買房間、不重置金幣。原有四房始終免費；在新翼按返回即回原有四房。八房地圖保留作右側次要入口，原有存檔與功能不移除。

## 檢查方向

驗證七件證物的任意順序收集、81 種結論只有一個成立、錯誤證物與證詞關聯、門窗／時間／身份推斷、一次性獎勵、續查、觸控拉繩與取消、儲存失敗，以及中英／大小手機的固定版面。Android 需真機試玩確認操作手感，雲端錄影不代表已量測手機幀率。

## 本版實際驗證

- 186 個單元測試通過（29 個檔案），包含新案件、舊關卡、存檔與經濟。
- 24 個不同的相關瀏覽器測試通過：11 個新案件／四房新翼測試、9 個原有全景測試、4 個旅館動態與舊裝飾測試。涵蓋四種手機尺寸、中英文、觸控取消、一次性獎勵及儲存失敗；不是 24 部真機測試。
- TypeScript／Vite production build、Android `assembleDebug bundleRelease` 成功。APK 為 1.22／23，target SDK 36，debug 簽章有效，47 個網頁資產與 production build 完全一致。release AAB 只是未簽署的編譯檢查檔，未上載 Play。
- 實際錄影從原有進度開始，經介面購買書室、收集證物、拉繩、出示錯誤及正確證物、提交錯誤及正確推理，再返回酒店；沒有注入已解案件狀態。
