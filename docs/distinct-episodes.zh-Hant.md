# 1.4 不同故事、不同玩法

已按玩家試玩回饋重做主路線。現在只有四關，唔再將原有配房關反覆排列成 26 關。

1. **生日蛋糕失蹤事件**：調查腳印、糖霜、茶車絲帶，證據直接留喺畫面；三個證據齊先可指認住客。錯誤指認有具體回饋。結局揭曉卷卷為免蛋糕融化，將佢搬到陰涼地方。
2. **行李大暴走**：3×4 酒店通道，家具只可搬去相鄰空格，柱不可搬。玩家清出由旅行箱到小柚嘅通路，再出發觀看行李沿路行走。初始盤面至少需要四次家具移動才能通路，已用搜尋驗證可解，並非靠逐格亂撳過關。
3. **夢境房間的門**：現實種子、夢境雨水、現實攀藤、夢境門互相影響。時段可以隨時切換，錯誤次序唔會消耗道具或金幣；提示會直接解釋缺少嘅條件。夢夢與發光藤蔓有實際場景呈現。
4. **為每位住客找個家**：只保留原本第一個配房關。四位住客嘅需要直接顯示喺候客區上方，房內亦有文字條件；角色簡介只作額外介紹。

每關畫面長駐「目標」及「點樣操作」，成功後有獨立結局。冇手速倒數，免費重設及重玩。三個新關卡每關首次 500 金幣，配房關首次 50；重玩不重複派獎。

沿用舊錢包與 version-1 存檔。新增 `episodes` 完成清單；舊關卡 ID、舊故事結局、裝飾、場景及金幣仍保存，但舊重複關唔會出現喺新路線。三種新玩法各有本地草稿鍵，可於離開、重載或改語言後繼續。損壞草稿會安全重設該關，不清除錢包。

使用原創酒店、住客及新透明物件圖集：旅行箱、蛋糕、夢境藤蔓、鎖匙。示範截圖／MP4／GIF 由真實遊戲錄製，並非概念圖。新關仍屬首批可玩內容，難度及節奏需要玩家試玩回饋；瀏覽器驗證不能取代實體 Android 流暢度及觸覺測試。

驗證結果：125 項邏輯測試、21 項完整瀏覽器流程通過；文字位置修正後另覆核三個流程，四種尺寸關卡地圖亦無裁切。正式建置及 Android 1.4（versionCode 5）APK 編譯成功，簽章已驗證。
