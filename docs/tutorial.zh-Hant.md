# 第一晚互動教學

新玩家首次進入第一晚，四位住客排隊完成後，會看到畫面頂部的短提示及金色目標框。教學使用原本的角色、房間及拖放操作，沒有額外教學關卡或強制操作遮罩。

1. 點月毛，了解牠想看月光。
2. 月光房亮起；可以拖入，亦可以先選角色再點房間。
3. 月毛安排正確後，提示讓玩家自行處理其餘三位；不會逐個揭示答案。需要幫助時可按原有提示鍵。
4. 四位都已分房時，指出「入住」檢查鍵。仍使用正式驗證器，放錯不會獲獎。
5. 通關沿用原有慶祝及首次 50 金幣獎勵，解鎖第二晚。

放錯月毛時，教學會重新指出月光需求及月光房；其餘操作仍然可用。從房內拖走月毛、替換住客、重設、切換語言及開關設定，都會按實際分房狀態更新引導。角色到達房間前及全螢幕詳細面板開啟時，提示會暫時隱藏。

「跳過」會立即保存至獨立的 `midnight-check-in.tutorial.v1` 本機偏好，不改動關卡、金幣或佈置。完成第一晚亦會停止教學；舊存檔若已通過第一晚，同樣不會再顯示。若儲存不可用，當次仍可跳過，並提示下次可能再次出現。未通關、未跳過就離開，下一次進入第一晚會由頭引導。

所有文字均有繁體中文／英文。金框不攔截觸控；跳過鍵至少 44 CSS 像素高。系統「減少動態」會停用金框閃動。

## 驗證與示範

單元測試涵蓋階段推導、正確房間、放錯／替換、進度相容及偏好儲存。瀏覽器測試涵蓋實際拖動修正、通關、跳過後重新載入、雙語、尺寸變更及儲存失敗。

啟動 Vite 後執行 `node scripts/record-tutorial.cjs`，可在忽略版本控制的 `artifacts/` 產生五個階段截圖，以及完整教學的 H.264 MP4／25 FPS GIF。需要 Playwright Chromium、Playwright FFmpeg 及系統 ffmpeg；一般環境可先執行 `npx playwright install chromium ffmpeg`。雲端已安裝 Chromium 與系統 ffmpeg；Playwright 的下載域名受限，因此其錄影介面使用 `/workspace/.tooling/playwright` 下指向既有系統 ffmpeg 的本地工具連結，執行時設定 `PLAYWRIGHT_BROWSERS_PATH=/workspace/.tooling/playwright`。

錄影頁面使用 Phaser 本來支援的 Canvas fallback，避開雲端軟件 WebGL 的錄影瓶頸；應用程式及 Android 的 renderer 選擇保持原設定。示範不是手機效能測試，Android 仍需實機檢查觸控、瀏海及音效。
