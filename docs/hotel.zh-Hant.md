# 旅館佈置及聲音設定（里程碑 4）

## 用通關金幣佈置大廳

大廳新增「佈置旅館」入口。所有裝飾都只是外觀，不會改變怪物需求、線索、唯一解或通關獎勵。

| 裝飾 | 價格 | 畫面效果 |
| --- | --- | --- |
| 月牙迎賓燈 | 100 金幣 | 大門兩側增加暖金月牙燈 |
| 皇家絲絨地毯 | 200 金幣 | 大門前增加梅紫金邊地毯 |
| 星光屋徽 | 300 金幣 | 屋頂增加星徽與一排小燈 |

三款可以同時展示，購入後立即擺放；已擁有的裝飾可免費「收起」或重新「擺放」。金幣不足時購買按鈕不可用；同一款不會重複扣幣。全套 600 金幣，每晚首次通關獎勵 50，累積完成 12 晚即可購齊。沒有真實金錢付款或廣告要求。

購買及展示狀態保存在原有本機存檔，會保留先前的 20 關進度及金幣。即使後續再通關，裝飾也不會被清除。若本機儲存不可用，介面會提示目前變更只在本次遊玩保留。

## 音樂、音效與觸覺回饋

在標題、大廳、關卡、結算畫面的右上方可開啟「設定」。三項開關獨立儲存：

- 背景音樂：預設開啟；使用原創的短篇合成旋律循環播放。
- 音效：預設開啟；分房、錯誤、購買及通關有不同的本機合成音效。
- 觸覺回饋：預設關閉；開啟後在分房、錯誤、購買及通關時使用輕量回饋。

「測試音效與觸覺回饋」按鈕會依目前開關播放，不會扣金幣。聲音須在使用者操作後才啟動；切到背景時暫停，回到前景後按偏好與瀏覽器政策恢復。音樂與音效同時關閉時會暫停音訊處理。

所有聲音均為本機合成，沒有串流或外部錄音檔。Android 使用 Capacitor 官方 Haptics 外掛；支援的瀏覽器會使用震動 API，不支援的裝置會保持安靜，遊戲仍可正常操作。設定介面支援鍵盤焦點切換、Escape 關閉及小螢幕捲動。

## 測試與限制

單元測試涵蓋扣幣、重複購買、擺放狀態、舊存檔相容、偏好儲存、音樂循環防重複、靜音、背景暫停及原生／瀏覽器觸覺介面。瀏覽器測試驗證實際大廳畫面改變、全套購買、重新載入保留、各開關獨立作用及儲存失敗提示。

目前美術仍是原創向量圖形；音樂是基礎合成循環，正式配樂與更豐富音色可在後續打磨。Android 外掛已加入並同步，但 APK 組裝、實際喇叭音量、震動手感及原生背景行為尚待實機驗證。未接入廣告，未發佈遊戲。
