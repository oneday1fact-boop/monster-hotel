# 全螢幕遊戲操作介面

主遊戲只顯示晚數、房號、條件圖示和角色名字。左上為返回、提示、線索；右上為語言及設定。底部保留「入住」及重設。完整需求和房間說明仍可點角色名字或房間資訊鍵查看。

設定、語言、選關、裝飾及詳細資料均使用滿版遊戲面板，配合紫金色立體按鈕。設定以三個大型圖示開關呈現，語言使用繁體中文／English 大卡片。切換語言保留當前分房，從設定進入語言後會回到設定；偏好即時儲存。

圖示按鈕至少 44×44 CSS 像素，保留讀屏標籤、鍵盤焦點及 Escape 返回。窄螢幕面板可捲動；Android 延用原生沉浸式橫向設定，仍需實機確認瀏海和系統手勢。

`npm run review:record` 以瀏覽器整個畫面錄製，包含 DOM 操作按鈕，產生遊戲、設定、語言截圖及 MP4／GIF。影片不再只擷取 Canvas。
