# 1.8：幽靈洗衣房、金幣收成與動態質感

蛋糕案已離開遊戲畫面，第二關完全換成「幽靈洗衣房」。十關總數與其餘玩法保留。

## 新洗衣房

五列四行、七件物件：星星被單、晾衣架、衣籃、大被卷、毛巾架、洗衣籃及外套架。各有不同造型、顏色及文字；橫放只左右、直放只上下，每次滑一格，不可穿過其他物件。玩家要騰出空間，將被單移到第二行右邊出口再送出。提供直接可見的方向按鈕及錯誤提示，沒有步數限額或倒數。

所有物件的碰撞與邊界由純邏輯驗證。廣度優先搜尋證實預設盤面最少十一個單格移動；指定演示路線亦每一步合法。保存中途物件位置，退出再回來可以繼續。

為保留舊完成紀錄、解鎖及一次性獎勵，內部沿用 `cake-case` ID；玩家只見到新洗衣房名稱及玩法。草稿改用 v4，舊的蛋糕調查草稿不會套入新謎題。完成過舊第二關者可直接重玩新遊戲，但不會重複取得 500 金幣。

## 金幣與按鈕

- 封面主按鈕由 294 收至 210 邏輯像素，字由 18 放大至 27，文案縮成「開始遊戲／Play」。大廳按鈕亦收窄並放大文字，沒有大外框。
- 首晚首次完成 50，事件首次完成 500，金額保持原樣。先記錄實際獎勵，再呈現金幣彈散、短暫停留、飛入錢包與數字跳升；粒子只係表現效果，不逐粒寫入存檔。
- 收成層不接收觸控，玩家可以直接按下一關；離開會清理動畫、數字更新及計時器。相同關卡重玩零獎勵，完全不彈金幣。
- 減少動態時改用靜態收據。音效及觸覺沿用玩家設定，沒有額外付費、廣告或隨機獎金。

## 各款玩法的動態

- 原本配房：保留四位住客入住及各自房內活動，通關加收成。
- 洗衣房：小豆換姿勢；衣物移位用短而平順的補間。
- 行李：小柚行走姿勢與原本旅行箱沿道路前進。
- 找不同：夢夢換姿勢及小星光；兩幅比較圖保持靜止，避免假差異。
- 升降機：卷卷姿勢、橫樑與左右台傾斜平滑過渡。
- 月光：月毛姿勢、流動光線與點亮星石的光暈。
- 手信：小柚姿勢、放入格子的輕微落位效果。
- 午夜事件：卷卷聆聽姿勢，事件卡交換位置有補間。
- 溫泉：燈燈姿勢、流動水線與浴池蒸氣。
- 派信：四位信箱住客原創姿勢錯開循環，小柚陪玩動態。

角色使用既有原創四姿勢圖集，配合細微位移、陰影及星光；這不是新增骨骼動畫。所有新增循環尊重系統減少動態設定，沒有改變謎題答案。實機流暢度需要 Android 手機確認。
