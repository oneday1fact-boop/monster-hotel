# 現行新住客：小熊維尼（1.16）

用戶要求以小熊維尼取代 1.15 的柴郡貓笑影。本版以 A. A. Milne 1926 年《Winnie-the-Pooh》的故事角色為基礎，使用重新繪製的無衣服小熊造型。保留 `clockwork-guest` 完成紀錄與儲存鍵，已解鎖的玩家自動看到維尼，不重置進度或重派金幣。

1926 年出版的原作在美國已於 2022 年進入公版。這不是全球公版聲明；各地期限、商標及現代改編權利需分別核對。例如英國通常採作者終身加七十年，不能僅憑美國期限推論當地可自由發行。本次只製作測試版本，沒有上架或擴大發行授權。

- 蜜糖棕色、圓耳、圓肚、布偶縫線、小粒眼睛及淺奶油色口鼻。
- 完全沒有衣服，沒有紅衫；旁邊是藍灰陶蜜罐及一隻小蜜蜂。
- 所有 SVG 路徑、配色、對白及動畫重新製作；沒有複製 Shepard 插畫或迪士尼影片畫面。
- 避免迪士尼版亮黃色身體、紅衫剪裁、特定臉部比例、字款、片段、歌曲、配音與合作標示。
- 「不穿紅衫」本身不構成版權安全保證；須同時區分原作、插畫、現代改編及商標。
