# 公版故事新住客：柴郡貓笑影

本版取材自 Lewis Carroll 1865 年出版的《Alice’s Adventures in Wonderland》第六章柴郡貓，使用原著「神秘笑容、能夠逐漸消失、會說話的貓」概念。作者於 1898 年去世；原作文字已在美國及通常採作者終身加 70 年的一般期限地區進入公版。公版不等於任何現代改編都可以使用。

## 本遊戲的原創表現

- 名字：笑影／Grin，角色類別直接稱柴郡貓／Cheshire Cat。
- 薄荷奶油色毛、金色眼睛、小月亮胸針、深藍灰短斗篷、帶透明尾尖與星點的長尾。
- 原創 SVG 路徑、造型、配色、故事、中文對白及動畫；沒有取用原著插畫或任何電影、電視、遊戲的圖像與聲音。
- 不使用現代改編的粉紫條紋、特定誇張咧嘴造型、商標、片名字樣或宣稱官方合作。
- 遊戲中能持續輕輕擺動；先以咕咕鐘關講述入住，再加入封面與大廳的共用隊列。
