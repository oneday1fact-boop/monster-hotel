# 1.20 試玩修正

此版接續 1.19 的「我的旅館」，不新增關卡或改動已賺金幣／獎勵。

## 我的旅館

住客目的地改用固定活動位置，與房前通道分開。每層狹窄通道一次只安排一段旅程，上落樓需要預留兩層出口；未輪到的住客繼續房內活動。排隊按可通行請求的先後處理，避免某位住客一直沒有出門機會。站在通道附近的住客會退後讓路，實際腳底位置決定畫面前後排序。中央樓梯不再拐過櫃枱。原畫中央大型櫃枱改為右側小登記台，樓梯至前方地毯有真正空出來的通道。

閣樓與花園翼在全景中有鎖定標記，可以開啟兩區擴建藍圖。這是預告，尚無擴建購買、價格或解鎖功能，不扣金幣。

## 解謎與介面

- 住客詳細卡改用與角色一致的個人高解像圖集，固定正方形，避免橫向拉長。
- 行李道路的左上入口固定，永遠接通外部入口；重新編排八步可解道路，保留點磚、撤回及重做。新增十字方向掣，方向代表空位移動方向。蜜罐、洗衣房及風鈴的四向掣亦統一十字排列。
- 影子牆加大；每件紙偶由三個橫向位置、兩段距離，改為五個位置、三段距離。要比較實際輪廓，不再顯示逐件答對數目。保留拖動預覽、取消及撤回。
- 枕頭球按畫面中的斜面法線作反射，保留接觸前的速度大小與切線速度；重力持續生效。球半徑、枕頭角度和碰撞寬度與圖像共用。較寬枕頭、風鈴範圍和籃口提供多種可行調法；淡線只預覽第一跳，上一發虛線可供比較。沒有隱藏的自動瞄準或碰撞後指定目標。
- 補齊第 14 關起各章關卡圖片，並為新增關卡保留離線預設封面。

## 存檔與驗證

保留完成紀錄、人物、照片、金幣及已購布置。舊影子六狀態位置按同等投影轉為十五狀態，歷史亦一同轉換；不更換完成身份。舊行李草稿若入口不符固定路磚，僅重開該道路草稿，已完成及獎勵不受影響；新入口草稿繼續保存。

測試包含十分鐘八住客模擬：腳底橢圓個人空間、樓梯單人、通道預留、每位都有旅程；全影子組合的唯一目標；反射速度與方向、多種可行枕頭配置；真實瀏覽器的手機比例、四向操作、舊草稿轉換、逐頁圖片載入、中英介面與無捲動版面。Android 真機流暢度需安裝確認，雲端影片不代表實測手機幀率。

最終驗證：170 項邏輯測試及 27 項不同的相關瀏覽器檢查通過；Android 1.20（versionCode 21）建置及 debug 簽章驗證成功，安裝包內 45 個網頁檔案與最終 production bundle 完全相符。實際錄影中的存檔仍為 8550 金幣、17 個已完成篇章，沒有瀏覽器程式錯誤。
