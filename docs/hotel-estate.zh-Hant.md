# 酒店全景與金幣擴建：1.21

大廳 → 我的旅館，保留原有四間房的生活畫面；左下新增「酒店全景 · 擴建」。全景是另外一個全螢幕八房剖面，可以隨時返回四房旅館。原有角色、四房動態、設定、金幣、關卡、照片及已購布置保留。

原有月光客房、花窗茶室、幽靈洗衣房、暖爐休憩室免費開放。兩翼另外有四間具備完整家具的房間：

| 樹屋書室 | 1,200 | 無 | 閱讀角、綠梳化、樹形書架；住客會走來閱讀 |

未解鎖時看到暗色房間、鎖及價格；點房間可拉近，閱讀簡短介紹後按金幣按鈕購買。取消預覽不花錢。開放後移除暗罩、亮燈，會邀請現有住客前來。四間合計 7,800 金幣，與原有裝飾／場景購買形成選擇，沒有新增付費貨幣。

## 行為與保存

全景使用原創八房背景與獨立的住客路線。已解鎖角色在開放房間之間移動、上落中央樓梯、點頭回應及做房內小動作；不會把新房變成一張沒有角色的商店圖。沿用單張原畫的分層連續動作，沒有在本模式循環切換姿態圖。近景放大有上限，避免任意放大。

解鎖寫入原有存檔的 `hotelRooms`。同一房只收一次；不足金幣、先決條件未滿或本機儲存失敗都不扣金幣。舊存檔預設保留四房，未知／重複房間 ID 會清理。購買不改變通關、裝飾或照片收藏。離線可購買及使用，沒有依賴伺服器。

提供四房返回、全景／近景、停一停、直接中英切換、設定及減少動態。所有面板為固定版面，不是可捲動清單。減少動態時仍直接顯示完整解鎖房間，不會停在遮住內容的閃光首格。

## 實際範圍

這一版的擴建是永久開放可住客使用的房間，不包含新謎題、樂器演奏互動、烘焙生產、掛機收入或照顧數值。廣告位置只有設計和獨立判定規則，未有 SDK 或可領取的廣告金幣。Google Play 封閉測試準備見 [交付說明](play-closed/README.zh-Hant.md)。
