# 1.12 角色動態與過關小劇場

難度、關卡次序、金幣價格及存檔規則沿用 1.11。

六種原創住客有各自節奏：狼人側頭聽聲、殭屍跳步、燈靈飄浮、木乃伊鞠躬、狐狸玩耍、食夢貘打瞌睡。選取時思考、有效操作後雀躍、無效操作時疑惑。動作作用於圖像，不移動點擊範圍，也不改變找不同的比較圖片。

十二個事件過關後展示不同小劇場：被單送回、行李抵達／送貨、好夢、月光亮起、手信封盒、熱茶、溫泉、接力舞蹈、香氛、轉匙及合照。小劇場不等待播完才開放下一關；首次獎勵先儲存，重玩不再派獎。

背景改為在入場及尺寸改變時繪製，解謎操作不再重建背景或停止其動畫。圖像姿勢以連續時間維持相位。以小量有上限的星光、透明度和位移呈現動感；離開關卡會移除劇場。減少動態效果模式保留靜態插圖與全部控制。

驗證包括背景在連續操作後保留、尺寸改變時刷新、不同角色反應、重玩不派獎、動畫期間直接進下一關、減少動態效果及既有完整關卡回歸。雲端瀏覽器錄影與 Android 編譯驗證不能保證實機幀率。
