# 1.25：連通旅館與神秘客突發事件

- 第一關關係條件移到獨立頂欄；隱藏同位置的關數徽章，讓上層兩間房的特性標籤完整顯示。中英文及大小手機都檢查重疊與溢位。
- 主目錄原「返回封面」的位置改為「委託賺幣」。返回封面變成語言掣旁的 Home 圖示；移除原旅館右下的重複賺幣大按鈕。未解鎖房間詳情仍有賺幣捷徑，完成後回原上下文。
- 移除偵探案件入口、證物／證詞／推理遊玩畫面及獨立新翼／八房地圖頁面。舊案件已賺金幣不回收；原 `teaCase` 資料只作舊存檔兼容，不再可進入或領取舊案件獎勵。
- 原館與新翼改為同一張 3400×900 遊戲世界。四間免費房不變，新翼沿同層玻璃長廊相連，共用同一批已解鎖住客、時間與動態。沒有另造一批新翼住客。

## 一間真正連通的酒店

原館在世界左側，新翼在右側，相距的區域是有插畫、地板和前欄杆的玻璃長廊。圖片只作場景美術；角色路線實際經過此區，換樓層只用兩幢建築各自的樓梯。新翼未買房之前沒有客人走入，買房後會邀請現有住客從原館過去。所有權、4800／7200／10800／15600 價格及先決條件沿用，不重收已購房間。

已擴建時預設近看長廊兩邊，保持房間大而清晰；「全館」可拉遠看到八房，亦可近看原館四房、新翼或單房、拖動鏡頭與跟住客。這些都是同一個掛載中的世界，不是切頁重建；跟隨鏡頭會陪同住客過橋。舊裝飾繼續顯示在原館四房。

玻璃廊是本項目新生成的原創透明插畫。以等比例視窗裁切呈現，另裁低欄杆作前景遮擋；角色經過時低欄遮腿、不蓋住臉。原館、新翼與角色圖保持原比例，沒有拉長人物。

## 突發事件〈神秘客的午夜行李箱〉

完成前四個**現行**章節（第一次配房、幽靈洗衣房、行李大步走、現實與夢境找不同）後，在我的旅館遇到黑衣客。首次該遊玩時段會由花園走近接待枱，之後留在場內等待互動，並有可見的「神秘客到訪」提示。未完成第四章不會出現，不以舊重複配房關卡編號代替條件。

客人拿三十年前的房卡要入住零號房；旅行箱打開星河，舊住客的行李自己湧出。玩家接手動態派送，沒有偵探證物簿或選口供答案：

1. 第一批：四件行李逐一出發，學會 A／B／C 三個道岔與四個房間。
2. 第二批：五件行李，最多兩件同時移動，需要留意下一件標籤。
3. 第三批：三件行李最多三件同時移動，每件依次經兩間房；到第一站後標籤更新，再回起點出發。

軌道、行李目標與下一批標籤直接可見，撳道岔改路。行李在實際路徑上連續移動；改道只影響尚未經過道岔的行李，不能把半路上的行李瞬移到另一分支。可以暫停規劃、逐步推進、放慢速度或重試本批。送錯房會自行飛回起點，已送到的行李保留，不扣命、不扣幣、沒有總倒數。文字與顏色一起識別房間，不要求單靠符號猜規則。

首次完成三批可領 **600 金幣**，旅館永久留下星河門燈；重玩為零獎勵。結尾將住客名單與三十年前的入住簿連起來，留下零號房伏線。零號房探索與下一次來訪尚未實作，門燈只提供重溫，不冒稱新增一間可購房。

## 存檔與驗證

原存檔增加可選 `visitorEvent`。保存批次、道岔、行李當前路段、進度、目的地順序和已領獎紀錄；離開或切語言可續玩，重新開啟時保持暫停，避免暗中送錯。角色模型在旅館的視角切換及購房時保留；旅館離開後不快轉走路時間。

所有派獎與買房先寫成功才播放效果；儲存失敗不扣幣、不增加獎勵或標記完成。原有主線、委託草稿、金幣、房產、裝飾、照片與已解鎖住客保持兼容。

可用 `npm test`、`npm run build`、`npm run test:browser` 驗證。`npm run review:record` 在 production preview（預設 port 5204）錄實際操作；需要 Playwright ffmpeg。錄影只預放舊四章完成紀錄與 5000 金幣，實際買書室4800、完成派送加600，結尾應餘800；沒有注入已完成事件狀態。
