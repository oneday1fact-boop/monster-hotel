# 二十晚入住手冊（里程碑 3）

四位住客維持月毛（狼人）、豆豆（殭屍）、燈燈（提燈妖）、卷卷（小木乃伊）。每晚各有四個房間；角色的基本心願不變，但房間配置與本晚額外線索會改變。

## 怎樣解謎

1. 從大廳進入「選擇關卡」，先玩已解鎖的夜晚。
2. 查看房間條件。後續房間可能同時具有月光、安靜、溫暖、乾爽等多項設施；「四種設施齊備」表示四項皆有。
3. 打開「本晚線索」。基本心願與額外線索必須全部成立。
4. 把住客拖入房間，或先點住客，再點房間。每房只住一位；被替換的住客回到等候區。
5. 按「安排全部入住」。若有線索不成立，可查看角色卡上「今晚的額外線索」，再調整位置。

旅館現在是兩層四房橫切面：101／102 在一樓，B01／B02 在地下層；左右順序與畫面一致。**同層左右兩房才算相鄰；上下層不相鄰；「左邊」亦必須同層。**詳見 [四房橫切面](cutaway.zh-Hant.md)。

## 進度與獎勵

依序通關解鎖下一晚；已完成夜晚可重玩。每晚首次完成獎勵 50 金幣，20 晚合共 1,000 金幣。重玩不會重複獎勵。沿用原有本機存檔格式，第 1 晚的舊進度與金幣會保留。語言偏好獨立儲存；目前關卡內尚未完成的分房只保留在記憶體，返回選關或重新載入會重新開始。
