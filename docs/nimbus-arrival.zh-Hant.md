# 第十四關：暴雨夜，小雷迷路了

新住客小雷（Nimbus）係一隻原創小雲獸：柔軟雲毛、淡藍小爪、閃電形額毛、風鈴頸飾。四個向量姿勢支援清晰縮放。佢緊張就會打雷，擔心嚇親新朋友；燈燈邀請佢先到大廳飲杯熱茶。

## 玩法

六列五行固定走廊。四個方向掣吹動小雷，直到前方有牆或邊界才停。途中收集三個風鈴零件，全部收齊後停在右上大廳過關。要利用牆做停點；不是搬動路磚，也不是反應限時關。

最短路線十次吹風。有免費撤回、按目前狀態搜尋的提示、重新開始。停止途中不扣金幣。存檔保留位置、已收集零件及撤回歷史；最後一步中斷會補回應有完成，重玩不重複派獎。

## 劇情與進度

先看暴雨登場，再按「接小雷入嚟」開始。完成後燈燈送熱茶，小雷永久出現在大廳。首次完成 500 金幣，總關卡可得 6,550；商店價格仍維持原先選擇平衡。原有相片、布置、場景及金幣保留。大合照過關後可直接去新關，亦可返回相牆。

## 驗證

`npm test`、`npm run build`、`MONSTER_SOFTWARE_TEST=1 npx playwright test e2e/nimbus.spec.ts`。

測試包括十步可解、牆及收集規則、狀態提示、解鎖、首次獎勵一次、重新開啟、永久住客、中斷過關復原、四種屏幕及英文短屏幕。實際瀏覽器操作錄影另提供 H.264 MP4、GIF 與截圖。Android 實機幀率及震動手感仍須試玩。
