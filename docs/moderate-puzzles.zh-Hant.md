# 1.6：適中難度及三個新玩法

今次先試做七關路線。難度靠觀察、預先安排同空間推理，不加入倒數、付費重試或突然增加隱藏規則。實際難度仍需要玩家試玩調整，不能用自動測試代替試玩評價。

1. 首晚配房：保留迎賓、四位住客與原本條件。
2. 蛋糕案：暫時保留實物線索、證據縮圖及推理，未擅自更換搜證玩法。
3. 行李大暴走：由三乘三加至四乘四，十五塊道路、一個空位。只可滑動相鄰路磚；入口、出口及每段道路都要真正接通。預設盤面由解答作合法滑動產生，測試可完整還原，但沒有聲稱最短步數。
4. 現實與夢境：同樣五個不同，兩幅圖保留相同的大物件，改為燈飾小寶石、星紋、鑰匙角度、地毯刺繡、行李吊牌圖案。可點任一邊，兩邊同步圈出。提示只短暫標示一處範圍，不會代答或扣金幣。
5. 升降機唔肯郁：六件行李重量為 3、4、5、6、7、9kg。每邊三件、總重相同；6kg 易碎行李要放左邊緩衝台。畫面即時顯示重量及傾斜。點已裝行李可取回。窮舉驗證唯一分組：左 4+6+7、右 3+5+9，各 17kg。
6. 走失嘅月光：五乘四盤面、六面可轉向鏡子、三粒星石。光線即時反射，必須同時照亮全部星石並射入右邊月窗。窮舉全部 64 個鏡面組合，只有一個成功；光線可交叉，循環會安全停止。
7. 旅行手信拼盒：五件共十六格的形狀裝入四乘四禮盒。可旋轉、取回、重新安排，不能重疊或超出盒邊。預覽白點是放置錨點；接受所有合法滿盒解答，不強迫指定擺法。

所有規則直接顯示在關卡內。新關卡均保存中途進度；語言可切換。每個事件首次完成獎勵 500，首晚配房 50，重玩不重複發錢。新增關卡接續舊進度解鎖，不清除金幣、布置、場景或舊完成紀錄。地圖分頁而非捲動。

新玩法使用既有原創背景、行李素材及程式繪製的鏡子、光束與禮物，全部隨包離線提供。此版本是玩法試作，未聲稱經真人難度測試或實機效能測試。
