# 廣告位置方案：先保留遊戲流暢度

目前版本只包含廣告入口介面及位置判定規則，**沒有廣告 SDK、追蹤、廣告網路請求或可領取的廣告金幣**。本文件的金額與頻率是下一階段的建議，不代表本版已派發。

| 位置 | 建議做法 | 限制 |
| --- | --- | --- |
| 過關收成完成後 | 玩家自選「看短片 +100 金幣」，保留立即下一關 | 第一關不提供；只限首次通關；與補給共用每日兩次上限 |
| 酒店全景的補給位置 | 玩家主動選擇「看短片領小補給 +100 金幣」 | 完成至少三關才提供；不放在購買房間的確認步驟，亦不把解鎖綁定觀看 |
| 連續完成三關，按返回大廳之後 | 可選插頁廣告，待獎勵、存檔和畫面過渡完成才考慮顯示 | 首三關不插播；至少再完成三關、距上次至少三分鐘；不在下一關點擊後搶先插播 |

解謎操作、錯誤重試、設定、漫遊、點住客、購買房間、開啟遊戲及返回前景都不出插頁。現階段不建議橫額，避免佔用全螢幕酒店及操作空間。

`src/domain/adPolicy.ts` 只提供未來 provider 的可顯示條件：離線、背景、SDK 未備妥、同意狀態未允許或功能未啟用時一律不顯示。`OfflineAds` 仍回傳未完成觀看，不能派獎。每日上限、跨程序觀看交易、頻率記錄與真正 provider callback 去重尚未接線；正式接 SDK 前必須一併完成，不能把按鈕點擊當成觀看成功。

正式接廣告前，需確認廣告帳戶及應用 ID、實際目標受眾、同意流程、資料安全與私隱政策。開發和封閉測試先用供應商測試廣告，不能以真實廣告點擊測試收益。此版商店聲明應按實際「沒有廣告 SDK」核實；未來加入後再更新。
