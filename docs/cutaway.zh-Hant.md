# 四房橫切面與動畫入住（里程碑 5 修訂版）

本次按新的方向製作完整旅館橫切面：兩間一樓房、兩間地下房，中間有通道，底部是入口及等候隊伍。角色改成粗輪廓、簡化色塊的可愛卡通；先前較寫實的房間／角色插畫不會隨遊戲打包。

## 四個有差異的空間

| 房間 | 結構及家具 | 首關設施 |
| --- | --- | --- |
| 101 月光貴賓房 | 淡紫四柱床、金邊、高月窗、圓地毯 | 月光 |
| 102 清風布草閣 | 薄荷牆、布草架、盆栽、亮窗 | 乾爽 |
| B01 小墓穴地下室 | 石牆、天井小窗、軟墊棺形床、閱讀燈 | 安靜 |
| B02 暖爐工房 | 外露暖管、厚木家具、橘被、小暖爐 | 溫暖 |

上層為 101／102，地下層為 B01／B02，四個房間的畫面位置與規則引擎一致。房間佈景代表空間外觀；每晚實際設施看房卡及標籤，後續房間可同時提供多種設施。所有二十關都重新驗證唯一解，左右、同層、相鄰線索也已對應新地圖。舊存檔的通關編號與金幣保留；未完成分房一直只存於記憶體，因此無需遷移舊房號。

## 入住流程與動作

四位住客從入口逐個走進等候隊伍。點選／拖放後，角色離開隊伍，沿中央通道進入房間；已入住角色可再次點選或拖動換房，被替換的住客會回到等候區。

- 狼人月毛：左右望月，旁邊有淡入淡出的月牙泡泡。
- 殭屍豆豆：間歇小跳，維持伸手的可愛姿勢。
- 提燈妖燈燈：左右搖晃並呼吸發光。
- 木乃伊卷卷：身體輕擺，鬆開的繃帶尾跟著擺動。

目前是獨立的精靈圖／補間動作，尚非骨架或逐格角色動畫。系統若啟用「減少動態效果」，會略過入場、走動與待機循環。角色走動時暫停分房輸入，畫布提供 `aria-busy` 狀態；動畫完成後恢復操作。

## 驗證與測試 APK

86 項單元測試及 15 項瀏覽器測試通過，包括實際完成全部 20 關、排隊入場、沿通道入住、從房內拖動、替換住客、離線插畫、減少動態及商店／設定回歸。

此環境已裝好完整 JDK 21 及 Android SDK，`npm run android:apk` 已產生 debug APK，並通過 Android `apksigner` 簽章檢查。亦已檢查 APK 內有這次的卡通圖與四個 SVG 房間，沒有先前被否決的插畫資產。

目前沒有連接實機，也沒有加速模擬器所需的 `/dev/kvm`，因此尚未驗證真實裝置上的手感、聲音、震動與背景生命週期。這不是商店發佈版本，沒有發佈遊戲。

## 全螢幕與育成遊戲式生活感

遊戲畫布會鋪滿可用螢幕，不再固定比例留空邊；房間配置隨闊屏手機及平板伸展，角色和文字保持原有比例。旋轉或改變視窗大小會保留目前分房。Android 已加入沉浸式隱藏系統列的程式碼，並成功建置；仍需實機確認瀏海、手勢區及系統列行為。

房間增加持續動態：暖爐火光閃動、月光房微光、地下室浮光、布草閣蝴蝶；已入住角色被點選時會短暫出現愛心反應。方向是可愛育成／經營遊戲的生活感，沒有新增餵養或成長數值系統。
