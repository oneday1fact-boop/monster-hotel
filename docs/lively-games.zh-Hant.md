# 1.11 試玩修改

| 位置 | 改動 |
| --- | --- |
| 第一次入住 | 房間具有共用條件；必須同時推理避暖氣、同層及左右關係。唯一解保留原本四位入住位置。上方直接顯示規則，教學不再圈出答案。 |
| 幽靈洗衣房 | 滑動有小幅越位回彈、布料晃動及短暫星塵；不改碰撞規則。 |
| 行李大暴走 | 保留 4×4／十五路磚／單空格，初始解由十六步縮至八步。撤回、重做與道路草稿一起儲存；新移動會清除重做分支。舊道路草稿仍可繼續。 |
| 找不同 | 只縮小已找到的圓圈；保留原來觸控範圍與靜止比較圖片。 |
| 升降機 | 加兩位動態乘客，重量錯誤會震動提示，平衡後實際上升再過關。 |
| 旅行手信 | 滑鼠及觸控拖放。綠格可放、紅格不可放；放手才寫入，重疊、超界或取消不改原本擺位。點選／旋轉仍可使用。 |
| 怪物星光接力 | 取代寄信，三輪依次記住 3／4／5 個跳躍次序。可重播，錯誤只清除當輪輸入。觀看與作答狀態直接可見。 |
| 怪物大合照 | 六位住客晃動；綠圈亮起代表望鏡頭，可點擊定格。錯過等下一次，不扣分或清除其他住客。全員準備後按快門才賺取／收藏相片。 |
| 角色反應 | 保留原創姿勢圖集，目標旁增加角色，解謎後有小跳躍回應；定格住客停止動作。 |
| 主選單 | 移除歡迎文字；封面／大廳左上角顯示金幣圖案與數量；四按鈕於右邊中央形成兩行。封面開始按鈕往右下移。 |
| 商店 | 六款布置合計 9,600，三款場景合計 6,600；關卡總獎勵仍是 6,050。保留已有金幣、已購布置／場景及免費春日清晨。 |

所有關卡維持離線、繁中／英文、固定全屏、不收費重試及首次派獎一次。系統減少動態效果會關閉裝飾動畫；接力示範與相機可操作時機以清晰的靜態亮框表示。育成系統仍暫緩。

驗證：`npm test`、`npm run build`、`MONSTER_SOFTWARE_TEST=1 npm run test:browser`。新測試涵蓋拖放預覽、無效放置、觸控取消、撤回／重做保存、接力錯誤與拍照收藏，以及四種屏幕尺寸。雲端錄影使用實際瀏覽器操作及 Canvas2D，不能代表 Android 實機幀率或震動手感。
