# 房內角色活動

四位住客完成移動後，會在獲分配的房間持續活動；每套循環約 4.4–6.2 秒，沒有額外下載。

- 月毛：觀察移動的月光光斑、蹲低、撲跳、落地，再抖落星塵。
- 豆豆：連續練習三段小跳，符紙隨跳動飄起，落地有柔和波紋，再停下休息。
- 燈燈：三粒暖色火花沿橢圓軌道繞行，分前後景穿過角色，燈身轉動、浮起並發光。
- 卷卷：從線軸拉開繃帶、拉回捲好，最後顯出蝴蝶結及小閃光。

`src/game/roomActivities.ts` 管理房內道具、陰影、動作節奏及局部縮放。動畫移動角色容器內的圖層，分房／拖動用的外層位置保持穩定；房內觸控範圍加大，涵蓋撲跳及搖擺。重設、換關及重新分房會清除舊的動畫，避免循環累積。

目前是角色插畫配合程序動畫、變形及道具圖層，未加入逐格表情、骨骼或餵食／成長系統。動作不會改變房間條件或解謎答案。啟用系統「減少動態」時不建立活動循環與動態道具，保留原本靜態角色。

瀏覽器測試分別擷取四個角色區域，確認短時間內以及一個完整循環後仍有動作，並驗證入住可正常取得獎勵。既有測試繼續涵蓋減少動態、房內拖動、替換住客及 20 晚通關。

使用 `npm run review:record` 產生實際遊戲截圖、H.264 MP4 及循環 GIF。Android debug APK 可供後續實機確認流暢度和觸控手感；本次未有實體裝置連接。
