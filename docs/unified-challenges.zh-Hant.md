# 1.3 固定畫面與統一解謎路線

今次依照最新要求改動現有遊戲，並保留舊玩家資料。

- 主目錄移除包住選單嘅大框，只保留全版插畫同獨立遊戲按鈕。
- 封面固定用春日清晨，圓潤中英標題置頂中央。
- 「故事模式／住客故事簿」入口移除；六段可玩入住事件穿插到解謎挑戰，共用同一進度地圖及下一關按鈕。
- 不再宣傳「20 晚」或固定總關數。現有內容為 26 個階段，之後可擴充；今次沒有額外新增劇情。
- 地圖每頁 12 關、布置每頁 3 款、場景每頁 2 款，全部用頁鍵。長角色／房間／線索介紹亦逐頁顯示，無需捲動。
- 六套明顯布置套用四間客房及大廳：月牙燈、心心地毯、星光燈串、花箱、玫瑰窗簾、甜點茶車。新圖為原創透明圖集，不是角色或電影素材。
- 預覽會展示真實四間客房，有原本／效果切換；確認先收費。取消、重複套用及收起不扣金幣。
- 場景永久購買：春日清晨隨遊戲附送；午夜 120、秋日 150、冬日 200 金幣。可隨時自由套用到大廳及一般解謎佈景。劇情關卡保留故事時間／季節，並不需要購買才能解鎖。

## 舊資料與金幣

沿用 version-1 存檔；原有完成關卡、事件結局、道具草稿、金幣、裝飾擁有及顯示狀態保留。已完成舊關仍可重玩，未完成內容按統一路線解鎖。舊版本當時選中嘅場景免費保留，唔會追收金幣；其他場景按新商店規則買入。新 `scenes` 欄位可選，不影響舊存檔讀取。

現有全部關卡首次完成合計 1,455 金幣，六套裝飾合計 950，付費場景合計 470；全部買齊仍餘 35。關卡重玩不重複派獎。無廣告或現金購買。

## 驗證與示範

`npm test` 驗證約束、唯一解、解鎖、結局、舊資料及交易。`npm run test:browser` 已將舊獨立故事簿及免費場景測試遷移為統一路線，並實際走完所有階段。固定畫面檢查會比較內容尺寸與容器尺寸，確保並非單純隱藏捲軸，另外檢查按鈕有否超出屏幕。涵蓋 844×480、915×412、640×320 及直向後備版面。

`scripts/record-unified.cjs` 記錄真實遊戲，商店展示用測試存檔（1,000 金幣及已擁有布置）；不會改變新玩家起始金幣。輸出 PNG、H.264 MP4 及 GIF。手機流暢度、觸覺及安裝仍需實體 Android 驗證，瀏覽器測試並不代表真機測試。

本次結果：123 項邏輯測試及 25 項瀏覽器測試全部通過；正式建置及 Android 1.3（versionCode 4）debug APK 編譯成功。實體 Android 尚未試玩。
